## Cách ôn

1. Trả lời ngắn bằng lời của mình, rồi giải thích bằng một ví dụ trong dự án.
2. Nói rõ grain, transaction boundary hoặc failure mode liên quan.
3. Phân biệt cơ chế đã có, ca đã kiểm thử và phương án chưa triển khai.
4. Nếu câu trả lời cần sơ đồ, dùng [kiến trúc và ERD](../architecture/README.md).
